Archive System
How rating tags control Public/Archived visibility and badge colors.

Overview

The current system uses rating tags with suffix (ra) to separate regular content from archived content.

  • questionable (ra) means archived and renders a yellow badge.
  • explicit (ra) means archived and renders a red badge.
  • Any other rating-like text is ignored by rating detection.

Strict Rating Parsing

Rating detection is strict. Only exact canonical forms are recognized (case-insensitive):

  • Questionable (ra) / questionable (ra)
  • Explicit (ra) / explicit (ra)

Examples that are not recognized:

  • R-18, 18+, 16+
  • ra: explicit, explicit ra, explicit (rating)

Badge Colors

Visual mapping is fixed:

Archived = questionable (ra)

Archived = explicit (ra)

If you see a wrong color on one page, check whether the video has canonical tags in metadata and whether that page is reading canonical video tags.

Filter Modes

all

Show all videos regardless of rating tag.

general (Public)

Show only videos with rating result safe (no recognized archived rating tags).

archived

Show only videos with rating result questionable or explicit.

Tagging Recommendation

  • Use exactly one archived rating tag per video when needed.
  • Prefer canonical forms: Questionable (ra) or Explicit (ra).
  • Avoid legacy labels in tags such as R-18 or 18+.
